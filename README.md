# Advanced ToDo App

An Advanced ToDo application built using Flutter that helps users organize daily tasks efficiently. The app uses the MVC architecture and stores data locally using SQLite (sqflite).

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Local SQLite Database
- MVC Architecture
- Clean and Responsive UI
- Persistent Data Storage
- Fast Performance

## Tech Stack

- Flutter
- Dart
- SQLite (sqflite)
- MVC Architecture

## Project Structure

```
lib/
├── controller/
├── database/
├── model/
├── screens/
├── widgets/
└── main.dart
```


## Database

The application stores all tasks locally using SQLite (sqflite), allowing users to access their tasks even without an internet connection.
